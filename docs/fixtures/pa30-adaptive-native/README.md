# Original native adaptive Huffman candidates

These four native PA30/PA31 controls use deterministic 65,536-byte xorshift32 data seeded with 5071, with one 4,096 or 8,192-byte run copied from an earlier position. Public CreateDeltaB and ApplyDeltaB exactly reproduced every target from an empty source, with SHA-256 and fixed FILETIME. `generate_inputs.py`, native scripts, manifests, hashes and execution evidence retain the bounded inputs and oracles. The independent native outputs also underpin the Rust regression `native_adaptive_streams_reconstruct_with_incomplete_huffman_tables`, which explicitly asserts at least one incomplete coded Huffman tree and exact reconstruction of all four targets. Native acceptance alone does not establish tree shape; this decoder-level assertion supplies that proof.
