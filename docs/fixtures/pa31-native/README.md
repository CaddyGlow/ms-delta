# Native PA31 known answers

Sixteen successful native RAW PA31 deltas cover eight original deterministic inputs: empty, `abc`, all byte values, random data, repeated text, identical source/target, changed source and the reverse change. Each uses SHA-256 and fixed FILETIME 132537600000000000, file-type set/type 1. Flags `0x10000000` and `0x18000000` both select PA31. Native `ApplyDeltaB` exactly reproduced the expected target and preserved source files. Input hashes, patch hashes and native header fields are retained in `manifest.json`; `execution.json` and `native-results.json` preserve the native run. `generate_inputs.py` regenerates original input bytes with xorshift32 seed 5071 where applicable.

The separate `bsdiff` matrix adds eight successful native cases with `0x1a000000`, including source-dependent changes. Requests with `0x12000000` returned native creation error 13 for all eight inputs; those failures remain in that matrix's manifest and are excluded from successful codec claims. Its source/target paths refer to the parent inputs. This establishes that the tested BSDiff bit `0x02000000` requires the additional tested bit `0x08000000` for native creation under this exact RAW configuration.

## Provenance and reproduction

The oracle DLL was downloaded from Microsoft's symbol server, key `E896309483000`, into the local cache as `UpdateCompression-24h2.dll`; SHA-256 is `2a12118232d0faab12bc8c768391ebd75c9160674a68c7cf8ac4bb24bdd2eefa`. The Microsoft DLL is not included here. Public exports `CreateDeltaB`, `GetDeltaInfoB`, `ApplyDeltaB` and `DeltaFree` were called by the original wrapper in `generate.ps1`, compiled by guest .NET Framework compiler 4.8.4084.0. The disposable Windows 10 build 19045.5073 guest was `cbs-psfx-pre-esu-1004`, with `VM_NET=none`; this newer DLL loaded and ran successfully on that guest.

For native reproduction, place the pinned DLL as `C:\pa31-oracle\UpdateCompression.dll`, copy `inputs.json` and all `.source`/`.target` files into that directory, then run the selected `generate.ps1` with PowerShell `-NoProfile -ExecutionPolicy Bypass -File`. The script emits native deltas and `matrix-results.json` in the same guest directory. Preserve regenerated proof separately. No fixture DLL or executable is executed. These bounded cases establish native behavior for the represented flags and vectors, not all PA31 graphs or creation options.

`reverse` retains ten native ApplyDeltaGetReverseB reverse-playback blobs whose application to the new target recovers the old source. `reverse-extended` adds unmanaged PE32/AMD64 relocation normalization, managed signatures, and a compressed 70,000-byte deleted tail. All four extended cases passed. Their manifests explicitly identify reversed source/target roles. `header-variants` retains controlled nested-header mutations: native accepts third field 0 or 1 in the tested triples and rejects third field 2 with error 262659; the first two tested fields can differ from 136 and 1 without native rejection.
