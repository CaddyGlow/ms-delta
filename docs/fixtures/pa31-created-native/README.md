# Rust-created PA31 native validation

All 18 Rust-created PA31 patches reproduced their exact targets under native `UpdateCompression.dll` `ApplyDeltaB`. The matrix covers eight original RAW vectors, forward/reverse I386 and AMD64 pointer-heavy unmanaged images, and forward/reverse signatures-rich managed AnyCPU, x86 and x64 assemblies. Native `GetDeltaInfoB` confirmed the represented RAW, unmanaged and modern managed graphs, SHA-256 and zero target FILETIME. Source SHA-256 values remained unchanged. The manifest records portable input paths, hashes, patch sizes and inline native proof; `execution.json` and `native-results.json` retain the independent run.

`generate.py` copies original inputs from the sibling `pa31-native`, `pa30-created-pe-native` and `pa30-created-cli-native` fixture trees and invokes `create --format pa31`, with `--pe` for typed cases. Original input generators and compiler provenance remain in those trees. No Microsoft payload or DLL is checked in. The resulting PA31 frame uses the implemented native-compatible wrapping of the corresponding PA30 compression stream; this matrix does not claim source-dependent BSDiff creation.

The pinned oracle was Microsoft's symbol-server `UpdateCompression.dll`, key `E896309483000`, SHA-256 `2a12118232d0faab12bc8c768391ebd75c9160674a68c7cf8ac4bb24bdd2eefa`, file version `5.00 (WinBuild.160101.0800)`. It loaded successfully on the isolated disposable Windows 10 build 19045.5073 guest `cbs-psfx-pre-esu-1004` with `VM_NET=none`. `apply.ps1` uses only public oracle exports for validation and compiles its original wrapper with .NET Framework compiler 4.8.4084.0.

For reproduction, build with `cargo build --locked -p windows-delta --features cli`. Run `WINDOWS_DELTA_CLI=/absolute/path/to/windows-delta python3 generate.py` in a disposable copy with generated outputs removed; the CLI refuses existing outputs. Place the pinned DLL at `C:\pa31-oracle\UpdateCompression.dll`. Transfer inputs/deltas as the names in the manifest into `C:\pa30-created-cli-oracle`, alongside `manifest.json` and `apply.ps1`, then run PowerShell `-NoProfile -ExecutionPolicy Bypass -File C:\pa30-created-cli-oracle\apply.ps1`. Preserve fresh native proof separately.
